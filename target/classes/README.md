# Wireless Books
## What it is
Wireless Books is a mod built for Paper MC. It allows you use commands to make books that you don't need a physical item for, and also is sharable.




## Usage
Creating books
/book create \[name\]

Removing Books
/book remove \[name\]

Editing Books
/book edit \[name\] \[name|contents\]

Sharing Books
/book access \[add|modify|remove\] \[name\]\ \[edit|view\]
- Using the modify type will swap which type of access the user has.
